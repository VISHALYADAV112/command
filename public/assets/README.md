# Command visual assets

All files are SVG so they stay sharp as Notion uploads and can be exported to PNG at any required scale.

- `bindu-filled.svg`, `bindu-hollow.svg`: individual status marks.
- `bindu-state-0.svg` through `bindu-state-4.svg`: the four-dot status from zero to four floors met.
- `gate-mark.svg`: section-label gate.
- `divider-small.svg`, `divider-medium.svg`, `divider-large.svg`: 320, 640, and 960 pixel double rules.
- `database-*.svg`: Daily Log, Learning, Job Hunt, People, Projects, and Ideas icons.
- `page-cover.svg`: 1500 × 500 dark cover with a clear centre.
- `gazette-mark.svg`, `gazette-icon-*.svg`: Gazette application marks.
